Deploying this site. It's a static site — push this repo and enable GitHub Pages (Settings → Pages → Deploy from branch → root). The .nojekyll file is already included so every file is served as-is.

Previewing locally? The strategy/research pages fetch Markdown files, so open the folder through a tiny web server rather than file:// — e.g. python3 -m http.server, then visit http://localhost:8000/. The three hubs open fine on their own either way.
